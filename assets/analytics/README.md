# Public analytics assets

These are the only analytics images approved for the public portfolio. Confidential originals must remain outside the GitHub repository. The homepage references this directory so each approved derivative remains external and easy to replace.

| Public file | Evidence scope |
| --- | --- |
| `channel-overview.png` | Channel views and watch time |
| `channel-reach.png` | Channel impressions and overall CTR |
| `long-video-overview.png` | Upload B's views, watch hours, and subscribers gained |
| `long-video-reach.png` | Upload A's impressions, CTR, views, and unique viewers |
| `short-overview.png` | Breakout Short views and subscribers gained |
| `short-engagement.png` | Breakout Short engagement metrics and chart |
| `content-formats.png` | Approved Short publishing evidence without the upload title or thumbnail |
| `content-live.png` | Approved live-content evidence without upload titles or private columns |

Create replacement derivatives from the private source archive outside the repository, inspect them at full size, and commit only the redacted approved output.

The gallery labels describe packaging direction rather than copying upload titles or assigning unsupported performance claims. Before publishing replacements:

- confirm permission to display the work;
- remove confidential client or audience details;
- preserve the correct horizontal or 9:16 aspect ratio;
- update the matching dimensions, alt text, and caption in `index.html`;
- optimize file size where practical without materially degrading text or image quality.
